# คู่มือการใช้งานระบบ Wae Jer Logistic (User Manual)

คู่มือนี้อธิบายวิธีการใช้งานระบบแบ่งตามบทบาทของผู้ใช้งาน ได้แก่ **ผู้ดูแลระบบ (Admin)** และ **พนักงานขับรถ/เซลส์ (Driver)**

---

## 👨‍💼 ส่วนที่ 1: คู่มือสำหรับผู้ดูแลระบบ (Admin)

ระบบสำหรับ Admin เป็น Web Application ที่ใช้งานผ่านคอมพิวเตอร์ (Desktop) สำหรับจัดการและติดตามการทำงานของทีมรถขนส่ง

### 1. การเข้าสู่ระบบ (Login)
* **วิธีใช้งาน:** เปิด Web Browser เข้าไปยัง URL ของระบบสำหรับผู้ดูแล (เช่น `/admin`)
* **ฟีเจอร์:** กรอก Username และ Password ของคุณเพื่อเข้าสู่ Dashboard หลักของระบบ

### 2. การจัดการสต็อกสินค้า (Inventory & Van Refill)
* **วิธีใช้งาน:** ไปที่เมนู **"Inventory"** (หรือ **"สต็อกสินค้าและคลัง"**)
* **ฟีเจอร์:**
  * **ดูสต็อกหลัก (Master Stock):** ตรวจสอบจำนวนสินค้าคงเหลือในคลังสินค้าหลัก
  * **เติมของให้รถ (Van Refill):** กดปุ่มทำรายการเพื่อเติมของ เลือกรถหรือพนักงานเป้าหมาย (เช่น V-01) ระบุจำนวนสินค้าแต่ละรายการที่ต้องการนำขึ้นรถ จากนั้นกดยืนยัน ระบบจะทำการหักสต็อกจาก Master และนำไปเพิ่มในสต็อกของรถคันนั้นทันที

### 3. การติดตามรถและพิกัดร้านค้า (Map Overview / Fleet Tracking)
* **วิธีใช้งาน:** ไปที่เมนู **"Map Overview"**
* **ฟีเจอร์:** ระบบจะแสดงแผนที่พร้อมหมุดพิกัดของร้านค้าต่างๆ แอดมินสามารถติดตามดูได้ว่าพนักงานเดินทางไปถึงร้านใดแล้วบ้าง (สีของหมุดอาจเปลี่ยนไป เช่น กลายเป็นสีเขียวเมื่อร้านนั้นถูกเยี่ยมแล้ว) นอกจากนี้ยังสามารถดูรายละเอียดและยอดขายของร้าน รวมถึงกดปุ่มขอดูเส้นทางนำทาง (Get Directions) ได้

### 4. การตรวจสอบการสำรวจร้านค้า (Survey Audit)
* **วิธีใช้งาน:** ไปที่เมนู **"Survey Audit"**
* **ฟีเจอร์:** เมื่อพนักงานหน้างานส่งข้อมูลรูปถ่ายและสถานะร้านค้า (เช่น ร้านเปิด, ปิด) เข้ามา แอดมินมีหน้าที่ตรวจสอบความถูกต้องของภาพถ่ายและตำแหน่ง GPS จากนั้นเลือกกด **"อนุมัติ (Approve)"** หรือ **"ปฏิเสธ (Reject)"**

### 5. รายงานยอดขายและกระทบยอดเงิน (Sales Reports)
* **วิธีใช้งาน:** ไปที่เมนู **"Sales Reports"** (หรือ **"รายงานยอดขาย"**)
* **ฟีเจอร์:** ใช้ตรวจสอบยอดขายรวมที่เกิดขึ้นในแต่ละวัน ดูรายละเอียดรายการขาย (Sale Items) แต่ละบิล และใช้ตัวเลขในระบบเปรียบเทียบกับยอดเงินสดหรือสลิปโอนเงินที่พนักงานนำมาส่งมอบตอนจบวัน เพื่อทำการปิดยอดบัญชี

---

## 🚚 ส่วนที่ 2: คู่มือสำหรับพนักงานขับรถ (Driver)

ระบบสำหรับพนักงานขับรถเป็น Mobile Web Application ที่ออกแบบมาให้ใช้งานผ่านโทรศัพท์มือถือ เพื่อความสะดวกในการทำงานลงพื้นที่

### 1. การเข้าสู่ระบบผ่าน LINE (LINE LIFF Login)
* **วิธีใช้งาน:** เปิดแอปพลิเคชัน LINE บนมือถือ เข้าไปที่ห้องแชทของระบบแล้วกดลิงก์หรือปุ่มที่เมนู (Rich Menu)
* **ฟีเจอร์:** ระบบจะทำการล็อกอินให้อัตโนมัติด้วยบัญชี LINE ของคุณ (ไม่ต้องจำและกรอกรหัสผ่าน) ทำให้พร้อมเริ่มงานได้ทันที

### 2. การตรวจสอบสต็อกบนรถ (Van Stock Check)
* **วิธีใช้งาน:** เมื่อเข้าสู่หน้าหลักของระบบ ให้ตรวจสอบรายการสินค้าและจำนวนในคลังรถของตนเอง
* **ฟีเจอร์:** ใช้เพื่อเช็คดูว่าจำนวนสินค้าที่แสดงในแอปพลิเคชัน ตรงกับจำนวนสินค้าจริงๆ ที่มีอยู่หลังรถหรือไม่ ก่อนที่จะออกเดินทางไปหาร้านค้า

### 3. ดูแผนที่และเริ่มเดินทาง (Check-In Map)
* **วิธีใช้งาน:** เลือกไปที่เมนู **"แผนที่ร้านค้า (Check-In Map)"**
* **ฟีเจอร์:** ดูพิกัดร้านค้าทั้งหมดที่ต้องไปเยี่ยมชมในวันนั้น สามารถใช้เป็นแผนที่นำทางไปยังจุดหมายแต่ละจุดได้

### 4. การเช็คอินและสำรวจร้านค้า (Check-in & Store Survey)
* **วิธีใช้งาน:** เมื่อเดินทางมาถึงร้านค้าเป้าหมาย ให้เลือกร้านนั้นบนแอปแล้วกด **"เช็คอิน"**
* **ฟีเจอร์:** 
  * ระบบจะดึงพิกัด GPS ปัจจุบันเพื่อยืนยันว่าคุณอยู่ที่หน้าร้านจริง
  * ให้คุณทำการถ่ายภาพหน้าร้านหรือภาพการจัดเรียงสินค้า
  * ระบุสถานะของร้าน (เช่น ร้านเปิดตามปกติ, ร้านปิด, หรือร้านปฏิเสธไม่รับสินค้า) จากนั้นกดยืนยันเพื่อส่งข้อมูลเข้าสู่ระบบส่วนกลาง

### 5. การเสนอขายและสั่งซื้อสินค้า (Digital Catalog & Sales Cart)
* **วิธีใช้งาน:** หากร้านค้ามีการสั่งซื้อสินค้า ให้เปิดหน้ารายการสินค้า (**Catalog**)
* **ฟีเจอร์:** 
  * เลือกสินค้าและใส่จำนวนที่ลูกค้าต้องการ (ระบบจะอิงจำนวนสูงสุดไม่เกินสต็อกที่มีบนรถของคุณ)
  * ดูการสรุปยอดเงินรวม (Total Amount)
  * กดยืนยันการสั่งซื้อเพื่อบันทึกการขาย

### 6. ระบบตัดสต็อกอัตโนมัติ (Auto Stock Deduction)
* **ฟีเจอร์:** ทันทีที่คุณกดยืนยันการขายสำเร็จ ระบบจะทำการหักลบจำนวนสินค้าออกจาก "สต็อกบนรถ" ของคุณโดยอัตโนมัติ ไม่ต้องกลับไปแก้ไขสต็อกเอง

### 7. สรุปยอดและจบวันทำงาน (End Day & Close Day)
* **วิธีใช้งาน:** เมื่อไปเยี่ยมครบทุกร้านแล้ว ให้เข้าไปตรวจสอบความเรียบร้อยที่ **"หน้าประวัติการเยี่ยมร้าน"**
* **ฟีเจอร์:** 
  * เช็คดูว่าวันนี้ไปร้านไหนมาบ้างและแต่ละร้านมียอดขายเท่าไหร่
  * กดปุ่ม **"สรุปยอดขาย (Close Day)"** เพื่อดูยอดเงินรวมทั้งหมดของกะนี้
  * นำเงินสดและสลิปการโอนเงินไปส่งมอบให้กับแอดมินหรือฝ่ายบัญชีที่ออฟฟิศ เพื่อเป็นการจบภารกิจในวันนั้น
