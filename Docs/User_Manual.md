# คู่มือการใช้งานระบบ Wae Jer Logistic (User Manual)

คู่มือนี้แบ่งตามบทบาทผู้ใช้: **ผู้ดูแลระบบ (Admin)** และ **พนักงานขับรถ/เซลส์ (Driver)**

---

## ส่วนที่ 1: คู่มือสำหรับผู้ดูแลระบบ (Admin)

Web Application ใช้งานผ่านคอมพิวเตอร์ (Desktop) เมนูอยู่ที่แถบด้านซ้าย (Sidebar)

### 1. เข้าสู่ระบบ
- เปิดเบราว์เซอร์ไปที่ `/admin` → กรอก Username / Password
- ครั้งแรกใช้ `admin` / `password123` แล้วไปเปลี่ยนรหัสที่เมนูโปรไฟล์ (มุมซ้ายล่าง) ทันที

### 2. หน้าแรก (Dashboard)
- สรุปจำนวนร้านทั้งหมด ร้านที่สำรวจแล้ว และการเยี่ยมในช่วงที่เลือก (วันนี้ / สัปดาห์ / เดือน)
- ตารางความคืบหน้าการสำรวจรายอำเภอ พร้อมช่องค้นหาอำเภอ

### 3. Map Overview (แผนที่ภาพรวม / ติดตามรถ)
- แผนที่แสดงขอบเขตอำเภอของโคราช (ระบายสีแยกอำเภอ) และหมุดร้านค้า — สีเขียว = สำรวจ/ขายแล้ว, สีแดง = ยังไม่สำเร็จ
- วงกลม = พื้นที่เป้าหมายสำรวจ (Geofence) ที่มอบหมายให้พนักงาน
- ตำแหน่งรถของพนักงานอัปเดตอัตโนมัติทุก ~30 วินาที
- เลือกวันที่เพื่อดู "เส้นทางการเดินทางย้อนหลัง" ของพนักงาน (GPS Trail)
- กดที่ร้านเพื่อดูรายละเอียด/ยอดขาย และปุ่มขอเส้นทางนำทาง (Get Directions)

### 4. จัดการพนักงาน (Employee Management)
- เพิ่ม/แก้ไข/ลบพนักงาน ระบุชื่อ เบอร์โทร ทะเบียนรถ รหัสรถ และพื้นที่รับผิดชอบ
- การเปลี่ยนชื่อพนักงานจะอัปเดตชื่อผู้เพิ่มร้าน (`created_by`) ในร้านที่พนักงานคนนั้นเคยเพิ่มโดยอัตโนมัติ

### 5. คลังสินค้าและสินค้า (Inventory) — 4 แท็บ
- **สต็อกรถ:** ดูสินค้าคงเหลือแยกตามคันรถ
- **คลังหลัก:** ดู/แก้ไขจำนวนสินค้าในคลังกลาง และทำรายการ "เติมของให้รถ" (โอนสต็อกจากคลังหลักขึ้นรถ — ระบบตัดคลังหลักและเพิ่มให้รถทันที พร้อมบันทึกประวัติ)
- **แคตตาล็อก:** เพิ่ม/แก้ไข/ลบรายการสินค้า (ชื่อ, SKU, หมวดหมู่, ราคา)
- **อ้างอิง POS:** ดูสต็อกสดจากระบบ POS (line-commerce) แบบอ่านอย่างเดียว มีช่องค้นหา + แบ่งหน้า และปุ่ม "นำเข้าจาก POS" เพื่อดึงแคตตาล็อกสินค้าจริงมาเป็นคลังหลักของ Cashvan

### 6. รายงานยอดขาย (Sales Reports)
- ดูยอดขายรวมตามช่วงเวลา (วันนี้/สัปดาห์/เดือน) และรายการบิลทั้งหมด
- กดที่บิลเพื่อดูรายละเอียดสินค้า พื้นที่ (อำเภอ/ตำบล) และพนักงานผู้ขาย
- ตารางเปรียบเทียบผลงานพนักงาน (ยอดขายรวม / จำนวนร้านที่ขายได้)
- ลบบิลที่ผิดพลาดได้ — ระบบจะคืนสินค้ากลับเข้าสต็อกรถ
- ใช้ตัวเลขในระบบกระทบยอดกับเงินสด/สลิปที่พนักงานส่งมอบ

### 7. ร้านค้าและผลสำรวจ (Store Survey) + ตรวจสอบผลสำรวจ (Survey Audit)
- ดู/แก้ไข/ลบข้อมูลร้านค้า (การลบจะลบยอดขายและประวัติการเยี่ยมของร้านนั้นด้วย)
- ในหน้าตรวจสอบผลสำรวจ ตรวจรูปถ่ายและข้อมูลที่พนักงานส่งมา แล้วกด **อนุมัติ (Approve)** หรือ **ปฏิเสธ (Reject)**

## ส่วนที่ 2: คู่มือสำหรับพนักงานขับรถ (Driver)

Mobile Web Application เปิดผ่านแอป LINE เมนูหลักอยู่แถบล่าง (แผนที่ / ร้านค้า-ขาย / สต็อก)

### 1. เข้าสู่ระบบผ่าน LINE
- เปิดลิงก์/เมนูของระบบในแอป LINE — ระบบล็อกอินให้อัตโนมัติด้วยบัญชี LINE
- ครั้งแรก: เลือกชื่อของคุณจากรายการเพื่อ **ผูกบัญชี** (ทำครั้งเดียว ครั้งต่อไปเข้าได้เลย)

### 2. หน้าแผนที่ (Check-In Map)
- แสดงพิกัดร้านค้าที่ต้องไป และวงกลมพื้นที่เป้าหมายที่ได้รับมอบหมาย
- ระบบส่งตำแหน่งของคุณให้ส่วนกลางอัตโนมัติ และบันทึกเส้นทางการเดินทางของวันนี้
- หากขึ้นแถบสีแดง "GPS ไม่ทำงาน" ให้กดอนุญาตตำแหน่งในเบราว์เซอร์แล้วรีเฟรช

### 3. รายการร้านค้า (ร้านค้า/ขาย)
- ค้นหาร้าน และกรองตามอำเภอ/ตำบล
- สลับแท็บ "ยังไม่ไป" / "เสร็จแล้ว" เพื่อดูความคืบหน้า

### 4. เช็คอินและสำรวจร้านค้า
- เลือกร้าน → ระบบตรวจว่าคุณอยู่ใกล้ร้านจริงหรือไม่ (จากพิกัด GPS)
- ถ่ายรูปหน้าร้าน (ระบบอัปโหลดขึ้นคลาวด์ให้)
- เลือกสถานะร้าน: สำเร็จ / ร้านปิด / ไม่พบร้าน แล้วกรอกหมายเหตุ → ยืนยัน
- หากเจอร้านใหม่ที่ยังไม่มีในระบบ กด "เพิ่มร้าน" ปักหมุดและกรอกข้อมูล

### 5. สต็อกบนรถ (สต็อก / แคตตาล็อก)
- เลือกคันรถของคุณ แล้วดูรายการสินค้าและจำนวนคงเหลือบนรถ
- ใช้ตรวจว่าจำนวนในระบบตรงกับของจริงบนรถก่อนออกเดินทาง

### 6. บันทึกการขาย
- เลือกสินค้าและจำนวนที่ลูกค้าสั่ง (ต้องเลือกคันรถก่อน) → ระบบคิดยอดรวมให้
- กดยืนยัน — ระบบจะตัดสต็อกบนรถอัตโนมัติ และตั้งสถานะร้านเป็น "สำเร็จ"

### 7. ประวัติการเยี่ยมร้าน
- ดูว่าวันนี้ไปร้านไหนมาแล้วบ้าง และยอดขายแต่ละร้าน

### 8. ปิดยอด / นับสต็อกปลายวัน (Close Day)
- กรอกจำนวนสินค้าที่เหลือจริงบนรถ — ระบบเทียบกับยอดที่ควรจะเหลือและแสดงผลต่าง
- ยืนยันปิดยอด แล้วนำเงินสด/สลิปโอนไปส่งมอบให้แอดมินหรือฝ่ายบัญชี

### 9. คู่มือในแอป
- กดไอคอนหนังสือที่มุมขวาบนเพื่อเปิดคู่มือแบบพลิกหน้า
