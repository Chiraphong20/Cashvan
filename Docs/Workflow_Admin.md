เอกสารนี้อธิบายลำดับขั้นตอนการทำงานในแต่ละวันของผู้ดูแลระบบ (Admin/Manager) ผ่านระบบ Wae Jer Logistic (Desktop Web Application)

## 🌅 1. การเตรียมความพร้อมก่อนเริ่มงาน (Start of Day)

หน้าที่หลักของ Admin ในตอนเช้าคือการเตรียมสินค้าให้พร้อมสำหรับรถแต่ละคัน (Van Refill)

1. **เข้าสู่ระบบ (Login):**
   - Admin ล็อกอินเข้าสู่ระบบผ่าน URL `/admin` ด้วย Username และ Password
2. **โอนย้ายสต็อก (Van Refill):**
   - ไปที่เมนู **"สต็อกสินค้าและคลัง" (Inventory)**
   - ตรวจสอบจำนวนสินค้าคงเหลือในคลังหลัก (Master)
   - กดปุ่มเพื่อทำรายการ **"เติมของให้รถ"**
   - เลือกรถเป้าหมาย (เช่น V-01) และระบุจำนวนสินค้าแต่ละรายการที่นำขึ้นรถ
   - กดยืนยัน ระบบจะทำการตัดสต็อกจาก Master และเพิ่มสต็อกให้ Van ทันที

---

## ☀️ 2. การติดตามและตรวจสอบระหว่างวัน (During the Day)

ระหว่างที่พนักงานขับรถลงพื้นที่ Admin จะทำหน้าที่ Monitor ผ่าน Dashboard

1. **ติดตามการเดินทาง (Fleet Tracking / Map Overview):**
   - ไปที่เมนู **"Map Overview"**
   - ระบบจะแสดงแผนที่และหมุดพิกัดร้านค้าทั้งหมด
   - Admin สามารถดูได้ว่าพนักงานเดินทางไปถึงร้านไหนแล้ว โดยสีของหมุดจะเปลี่ยนไป (เช่น ร้านที่เช็คอินแล้วจะเปลี่ยนเป็นสีเขียว)
2. **ตรวจสอบข้อมูลสำรวจร้านค้า (Survey Audit):**
   - เมื่อพนักงานส่งข้อมูลการเยี่ยมร้านและรูปถ่ายเข้ามา
   - Admin เข้าไปตรวจสอบความถูกต้องของรูปถ่าย สถานะร้าน (เปิด/ปิด) และพิกัด
   - Admin ทำการ **Approve (อนุมัติ)** หรือ **Reject (ปฏิเสธ)** ข้อมูลนั้นๆ

---

## 🌇 3. การสรุปยอดหลังจบวัน (End of Day)

เมื่อพนักงานทุกคนกลับมาถึงและปิดกะการทำงาน

1. **ตรวจสอบยอดขาย (Sales Reports):**
   - ไปที่เมนู **"รายงานยอดขาย"**
   - ดูยอดขายรวมที่เกิดขึ้นในวันนั้น ตรวจสอบรายการบิลขาย (Sale Items)
   - เปรียบเทียบยอดเงินที่ระบบคำนวณกับยอดเงินสด/สลิปโอนที่พนักงานนำมาส่ง
2. **จัดการทรัพยากร (System Management):**
   - หากมีร้านค้าใหม่ที่พนักงานเพิ่มเข้ามา Admin ตรวจสอบและบันทึกลงฐานข้อมูลหลัก
   - อัปเดตข้อมูลพนักงาน หรือจัดการรายการสินค้า (Products) หากมีการเปลี่ยนแปลงราคา

---

### 📌 สรุป Flow ของ Admin
`Login` ➔ `Van Refill (โอนสต็อก)` ➔ `Fleet Tracking (ดูแผนที่)` ➔ `Survey Audit (ตรวจสอบภาพถ่าย)` ➔ `Sales Reports (สรุปยอดขาย)`
