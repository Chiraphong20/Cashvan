# กรณีทดสอบระบบ (Test Cases)

Test Cases หลักสำหรับตรวจระบบ Wae Jer Logistic เมื่อมีการพัฒนา/อัปเดต — ปรับปรุงตามฟีเจอร์ปัจจุบัน

---

## 1. โมดูล: ระบบผู้ดูแล (Admin Web)

| Test ID | ฟีเจอร์ | ขั้นตอน | ผลลัพธ์ที่คาดหวัง |
| :---: | :--- | :--- | :--- |
| TC-A01 | เข้าสู่ระบบ | ไป `/admin/login` → กรอก `admin` / `password123` → เข้าสู่ระบบ | ไปหน้า `/admin` มีชื่อ Admin บน Sidebar |
| TC-A02 | Route Guard | เคลียร์ `localStorage` (`admin_user`) → พิมพ์ `/admin/map` ตรง ๆ | ถูก redirect ไป `/admin/login` |
| TC-A03 | แก้ไขโปรไฟล์ | เมนูโปรไฟล์ → แก้ชื่อ → บันทึก | ชื่อมุมซ้ายล่างเปลี่ยนทันที |
| TC-A04 | นำเข้าแคตตาล็อกจาก POS | Inventory → แท็บ "อ้างอิง POS" → นำเข้าจาก POS | แจ้งจำนวน สินค้าใหม่/อัปเดต/รวม; แท็บแคตตาล็อกมีสินค้าเพิ่ม; คลังหลักมีสต็อกตั้งต้น |
| TC-A05 | นำเข้า POS ซ้ำ | กดนำเข้าซ้ำอีกครั้ง | สินค้าเดิมอัปเดตข้อมูล แต่จำนวนสต็อก MASTER ไม่เปลี่ยน |
| TC-A06 | โอนสต็อกขึ้นรถ | Inventory → แท็บ "สต็อกรถ" → เลือก `V-01` → สินค้า 10 ชิ้น → ยืนยัน | MASTER ลด 10, `V-01` เพิ่ม 10, มีแถวใหม่ใน `stock_transactions` (TRANSFER) |
| TC-A07 | แผนที่ Fleet | เข้า "Map Overview" | GeoJSON อำเภอเรนเดอร์, หมุดร้านสีตามสถานะ, วงกลม geofence แสดง |
| TC-A08 | ตำแหน่งรถเรียลไทม์ | ให้ Driver ล็อกอินบนมือถือ → รอ ~30s → ดูแผนที่ Admin | หมุดตำแหน่งพนักงานปรากฏ/ขยับตาม `driver_locations` |
| TC-A09 | เส้นทาง GPS ย้อนหลัง | เลือกวันที่บนแผนที่ที่มี trail | เส้น Polyline เส้นทางของวันนั้นแสดง |
| TC-A10 | ตรวจสอบผลสำรวจ | SurveyAudit → เลือกร้าน status SUCCESS → Approve | `verification_status = APPROVED`; Reject → `status` กลับเป็น UNSURVEYED |
| TC-A11 | รายงานยอดขาย | SalesReports → ตัวกรอง "วันนี้" → เปิดบิล | รายละเอียดสินค้า/พื้นที่/พนักงานถูกต้อง; ลบบิลแล้วสต็อกรถเพิ่มกลับ |
| TC-A12 | จัดการพนักงาน | แก้ชื่อพนักงานที่เคยเพิ่มร้าน | `stores.created_by` ของร้านนั้นเปลี่ยนตาม (cascade) |

## 2. โมดูล: ระบบพนักงาน (Driver App)

| Test ID | ฟีเจอร์ | ขั้นตอน | ผลลัพธ์ที่คาดหวัง |
| :---: | :--- | :--- | :--- |
| TC-D01 | เข้าระบบ LINE + ผูกบัญชี | เปิด `/driver` ผ่าน LINE ครั้งแรก | เด้งไป `/driver/login` → เลือกชื่อพนักงาน → ผูกสำเร็จ → เข้าหน้าแผนที่ |
| TC-D02 | Bypass บน localhost | เปิด `http://localhost:3000/driver` | ล็อกอินเป็น `dev_user` โดยไม่เรียก LIFF |
| TC-D03 | ส่งพิกัด GPS อัตโนมัติ | ล็อกอินค้างไว้ ~30s (อนุญาต location) | มี POST `/api/driver-location` และแถว `driver_locations` อัปเดต |
| TC-D04 | GPS Trail | เปิดหน้าแผนที่ เดิน/ขยับตำแหน่ง | จุดสะสมถูกส่ง batch เข้า `/api/gps-track`; badge เส้นทางแสดงจำนวนจุด |
| TC-D05 | GPS ถูกปฏิเสธ | ปิดสิทธิ์ location แล้วเปิดหน้าแผนที่ | banner แดง "GPS ไม่ทำงาน" พร้อมข้อความวิธีแก้ |
| TC-D06 | กรองรายการร้าน | DriverStoreList → เลือกอำเภอ/ตำบล + สลับแท็บ ยังไม่ไป/เสร็จแล้ว | รายการและตัวเลขนับตรงตามตัวกรอง; ไม่เห็นร้าน `is_admin_only` / `NOT_FOUND` |
| TC-D07 | เช็คอิน + อัปโหลดรูป | เลือกร้าน → ถ่ายรูป → เลือกสถานะ → ยืนยัน | รูปขึ้น Cloudinary (หรือ fallback Base64); แถวใหม่ใน `visits`; เห็นใน SurveyAudit |
| TC-D08 | เพิ่มร้านใหม่ | ปักหมุด + กรอกข้อมูล → บันทึก | ร้านใหม่ `verification_status = PENDING`, `created_by` = ชื่อพนักงาน |
| TC-D09 | บันทึกการขาย | เลือกคันรถ → เลือกสินค้า 2 ชิ้น ชิ้นละ 100 → ยืนยัน | ยอดรวม 200; `sale` + `sale_items`; `inventory` ของ `V-01` ลด 2; `stores.status = SUCCESS` |
| TC-D10 | ขายโดยไม่เลือกรถ | พยายามบันทึกขายโดยไม่มี `vehicle_id` | API ตอบ 400 "Please select a vehicle" |
| TC-D11 | ปิดยอด | CloseDay → กรอกยอดนับจริง | แสดงผลต่างรายสินค้า; ยืนยันแล้วสต็อก VAN ถูกล้าง |
| TC-D12 | คู่มือในแอป | กดไอคอนหนังสือใน header | ManualEbook (flipbook) เปิดเต็มจอ พลิกหน้าได้ |
