# บทนำ (Introduction)

## 1. ที่มาและความสำคัญของระบบ Wae Jer Logistic

ธุรกิจโลจิสติกส์และการกระจายสินค้า (Distribution) โดยเฉพาะในรูปแบบหน่วยรถเร่ หรือ **Cashvan** มีความซับซ้อนสูง เนื่องจากต้องจัดการทรัพยากรหลายด้านพร้อมกัน ไม่ว่าจะเป็น พนักงานขับรถ, สินค้าในสต็อกที่อยู่บนรถ, แผนที่การเดินทางเข้าถึงร้านค้า, และการสรุปยอดขายในแต่ละวัน

ก่อนหน้านี้ การจัดการข้อมูลเหล่านี้มักจะทำผ่านกระดาษ หรือการสื่อสารผ่านแอปพลิเคชันแชททั่วไป ซึ่งทำให้เกิดความล่าช้า ข้อมูลตกหล่น และยากต่อการตรวจสอบของส่วนกลาง (Admin/Manager)

ระบบ **Wae Jer Logistic (Cashvan & Survey Management)** จึงถูกสร้างขึ้นเพื่อทำ **Digital Transformation** ให้กับกระบวนการทั้งหมด โดยมีจุดประสงค์เพื่อให้การนำสินค้าไปเสนอขายหน้าร้าน (Cashvan) และการเก็บข้อมูลสภาพร้านค้า (Survey) ทำได้อย่างเป็นระบบ ตรวจสอบได้แบบ Real-time และลดความผิดพลาดจาก Human Error

## 2. กลุ่มเป้าหมายผู้ใช้งาน (Target Users)

ระบบนี้ถูกออกแบบมาสำหรับ 2 กลุ่มผู้ใช้หลัก:

1. **ผู้จัดการ / ผู้ดูแลระบบ (Admin)**
   - กลุ่มคนที่นั่งทำงานอยู่ในสำนักงาน (Back Office)
   - ต้องการเห็นภาพรวมการทำงานของเซลส์และคนขับรถ
   - ต้องการตรวจสอบสต็อกสินค้าทั้งในคลังและบนรถ
   - ต้องการดูแผนที่เพื่อประเมินจุดกระจายสินค้าและวางแผนเส้นทาง

2. **พนักงานขับรถ / เซลส์หน่วยรถ (Driver)**
   - ผู้ที่ต้องลงพื้นที่จริง
   - ต้องการเครื่องมือที่ใช้งานง่ายบนมือถือ
   - ต้องการระบบเช็คอิน แผนที่นำทาง และแคตตาล็อกสินค้าที่ไม่ซับซ้อน
   - ต้องการให้การบันทึกยอดขายและสรุปยอดปลายวันเป็นเรื่องง่าย

## 3. ขอบเขตเอกสาร

เอกสารชุดนี้ทำหน้าที่เป็นคู่มือและข้อกำหนดทางเทคนิค (Technical Specification) สำหรับการพัฒนา บำรุงรักษา และขยายต่อยอดระบบ Wae Jer Logistic โดยจะครอบคลุมถึง:

- โครงสร้างและสถาปัตยกรรมของระบบ (System Architecture)
- การออกแบบฐานข้อมูล (Database Design & Data Dictionary)
- ข้อมูลจำเพาะทางเทคนิคและ API (API Documentation)
- ขั้นตอนและสภาพแวดล้อมในการพัฒนา (Development Environment)
- กระบวนการทำงานหลัก (System Workflows)

## 4. นิยามศัพท์ (Glossary)

| คำศัพท์ | คำจำกัดความ |
| :--- | :--- |
| **Cashvan** | รูปแบบการขายสินค้าโดยนำสินค้าขึ้นรถบรรทุกหรือรถตู้ แล้ววิ่งไปขายตามร้านค้าย่อยต่างๆ |
| **Store Survey** | การเก็บข้อมูลสถานะของร้านค้าย่อย เช่น ตำแหน่งพิกัด ถ่ายภาพหน้าร้าน ความต้องการสินค้า |
| **Van Stock** | สต็อกสินค้าที่อยู่บนรถ (แต่ละคันจะมีสต็อกแยกกัน) |
| **Master Inventory** | คลังสินค้าหลักของบริษัท |
| **Check-in** | การระบุตัวตนและยืนยันตำแหน่ง GPS ของพนักงานขับรถเมื่อถึงร้านค้า |
| **Digital Catalog** | รายการสินค้าแบบออนไลน์ที่พนักงานใช้เสนอขายหน้าร้าน |
