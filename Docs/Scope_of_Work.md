# ขอบเขตงาน (Scope of Work) - โครงการ Cashvan & Survey Management System

## ภาพรวมโครงการ
พัฒนาระบบบริหารจัดการรถขายสินค้า (Cashvan) และการสำรวจตลาด (Survey Management) เพื่อเพิ่มประสิทธิภาพในการติดตามการขาย การบริหารคลังสินค้า และการวิเคราะห์พื้นที่การขายในจังหวัดนครราชสีมา (Korat) โดยมุ่งเน้นการใช้งานที่ง่ายผ่านระบบแผนที่และการจัดการข้อมูลที่แม่นยำ

## กลุ่มผู้ใช้งาน (User Roles)
1. **ผู้ดูแลระบบ (Admin)**: ตรวจสอบภาพรวมธุรกิจ วางแผนเชิงกลยุทธ์ และติดตามการทำงานของทีมภาคสนาม
2. **พนักงานขับรถ/พนักงานขาย (Driver)**: ปฏิบัติงานนอกสถานที่ บันทึกการเข้าเยี่ยมลูกค้าร้านค้า และนำเสนอสินค้าผ่าน Catalog

## ขอบเขตความสามารถของระบบ (Functional Scope)

### 1. ระบบสำหรับผู้ดูแลระบบ (Admin Dashboard & Management)
- **แดชบอร์ดภาพรวม (Dashboard)**: แสดงตัวชี้วัดสำคัญ ยอดขาย และ**สถานะการทำงานรายวันของพนักงาน** (เพื่อให้ทราบว่าใครเริ่มงานแล้วและลงพื้นที่ไหน)
- **การจัดการพื้นที่ทำงาน (Territory Management)**: มอบหมายหรือระบุพื้นที่ที่พนักงานจะลงพื้นที่ในแต่ละวัน (ไม่ต้องใช้ Real-time Tracking)
- **การจัดการสต็อกบนรถ (Van Stock Management)**: บริหารจัดการสต็อกสินค้าที่อยู่ในรถแต่ละคันเพื่อนำไปขายจริง
- **การจัดการร้านค้า (Store Management)**: 
  - บันทึกพิกัดและข้อมูลร้านค้าโดยแอดมิน
  - ระบบคัดกรองสถานะร้านค้า: **"ยังไม่ได้สำรวจ"** และ **"สำรวจแล้ว"**
- **การเข้าถึงข้อมูลร่วม**: สามารถตรวจสอบ Catalog สินค้า, ผลสำรวจ และประวัติการเข้าเยี่ยมเช่นเดียวกับพนักงาน

### 2. ระบบสำหรับพนักงาน (Driver / LINE LIFF)
- **การจัดการสต็อกบนรถ**: ตรวจสอบจำนวนสินค้าที่มีอยู่ในรถพร้อมขาย
- **ระบบเช็คอินและสำรวจ (Check-in & Survey)**: 
  - ดูรายชื่อร้านค้าในพื้นที่ที่ได้รับมอบหมาย
  - บันทึกพิกัดและถ่ายรูปยืนยันหน้าร้าน
  - อัปเดตสถานะร้านค้าเป็น **"สำรวจแล้ว"**
- **แคตตาล็อกและประวัติ**: 
  - ใช้งาน Digital Catalog เพื่อนำเสนอสินค้า
  - ตรวจสอบประวัติการเข้าเยี่ยม (Visit History) ย้อนหลัง

## ขอบเขตทางเทคนิคและงานดีไซน์ (Technical & Design Scope)
- **Framework**: พัฒนาด้วย React และ TypeScript (Vite)
- **Design Experience (UX/UI)**: 
  - ใช้ "Precision Navigator" Design System
  - ธีมสีพรีเมียม (Premium Theme): ส้ม-ขาว-ดำ (Orange, White, and Black)
  - UI เน้นความทันสมัย (Modern Grid), Glassmorphism และ Micro-animations
- **API Integrations**: 
  - Google Maps Platform (Maps, Geocoding, Navigation)
  - Backend API สำหรับเชื่อมต่อฐานข้อมูล POS
- **Performance**:
  - รองรับการประมวลผลข้อมูลขนาดใหญ่ (High volume data processing)
  - ปรับแต่งความลื่นไหลของ UI ให้เหมาะสมกับอุปกรณ์พกพา
