# ขอบเขตของโครงการ (Scope of Work)

เอกสารนี้ระบุขอบเขตการทำงานของระบบ Wae Jer Logistic (Cashvan & Survey Management) ทั้งส่วนที่ครอบคลุม (In-Scope) และส่วนที่อยู่นอกเหนือขอบเขต (Out-of-Scope) — ปรับปรุงให้ตรงกับสถานะปัจจุบันของระบบ

---

## 1. สิ่งที่อยู่ในขอบเขต (In-Scope)

### 1.1 ระบบสำหรับพนักงานขับรถ (Driver Web Application) — Mobile-first

1. **ระบบยืนยันตัวตน (Authentication)**
   - เข้าใช้งานผ่าน LINE LIFF (`VITE_LIFF_ID`) โดยดึงโปรไฟล์ LINE อัตโนมัติ
   - หากยังไม่ผูกบัญชี ให้เลือกชื่อพนักงานจากรายการเพื่อ **ผูก (bind)** `line_user_id` กับ Driver (ทำครั้งเดียว)
   - ในเครื่อง localhost ระบบ bypass LIFF เป็นผู้ใช้ทดสอบ (`dev_user`)

2. **การติดตามตำแหน่ง (GPS Tracking)**
   - ส่งพิกัดปัจจุบันเข้า `/api/driver-location` อัตโนมัติทุก 30 วินาที ขณะล็อกอิน
   - บันทึกจุดเส้นทาง (breadcrumb) ลง `/api/gps-track` เพื่อสร้าง GPS Trail รายวัน
   - แสดง Trail ของวันนี้บนแผนที่ พร้อม banner แจ้งเตือนเมื่อสิทธิ์ GPS ถูกปฏิเสธ

3. **แผนที่และรายการร้านค้า**
   - แผนที่ (CheckInMap): หมุดร้านค้าตามสถานะ + วงกลมเป้าหมายสำรวจ (Geofence)
   - รายการร้าน (DriverStoreList): ค้นหา + กรองตามอำเภอ/ตำบล, แท็บ "ยังไม่ไป / เสร็จแล้ว"
   - ซ่อนร้านที่เป็น `is_admin_only` และสถานะ `NOT_FOUND` จากฝั่ง Driver

4. **การเช็คอินและสำรวจร้านค้า (Check-in & Survey)**
   - ตรวจระยะห่างระหว่างพิกัดปัจจุบันกับพิกัดร้าน (Haversine)
   - ถ่าย/อัปโหลดรูปหน้าร้าน — จัดเก็บบน **Cloudinary** (fallback บีบอัดเป็น Base64 800px คุณภาพ 60%)
   - เลือกสถานะการเยี่ยม: สำเร็จ / ร้านปิด / ไม่พบร้าน และกรอกหมายเหตุ
   - เพิ่มร้านค้าใหม่พร้อมพิกัด อำเภอ/ตำบล ประเภทร้าน เบอร์โทร

5. **การขายและสต็อกบนรถ**
   - ดูสต็อกบนรถของตนเอง (DriverStock / DigitalCatalog) โดยเลือกคันรถ (vehicle)
   - บันทึกออเดอร์ (SalesRecord) — คำนวณยอดรวมอัตโนมัติ, ตัดสต็อกรถทันที, สร้าง Visit สถานะ SUCCESS และอัปเดต `stores.status = 'SUCCESS'`

6. **ประวัติและปิดกะ**
   - ประวัติการเยี่ยมร้าน (VisitHistory)
   - ปิดยอด/นับสต็อกปลายวัน (CloseDay) — เทียบยอดคาดหวังกับยอดนับจริง, แสดงผลต่าง, คืนสต็อก

7. **คู่มือการใช้งานในตัว (ManualEbook)** — หนังสือแบบเปิดหน้า (flipbook)

### 1.2 ระบบหลังบ้านสำหรับผู้ดูแล (Admin Web Application) — Desktop-first

1. **ระบบยืนยันตัวตน (Admin Authentication)**
   - ล็อกอินด้วย Username/Password (SHA-256) — เก็บ session ใน `localStorage` (`admin_user`, `admin_token`)
   - ทุกหน้าใน `/admin/*` ถูก guard โดย `AdminLayout` — ไม่มี session จะ redirect ไป `/admin/login`
   - จัดการโปรไฟล์ (เปลี่ยนชื่อ, เปลี่ยนรหัสผ่าน)

2. **แดชบอร์ดและการรายงาน**
   - หน้าแรก: สรุปความคืบหน้าการสำรวจ, จำนวนร้าน, การเยี่ยมในช่วงเวลา (วันนี้/สัปดาห์/เดือน), ความคืบหน้ารายอำเภอ
   - รายงานยอดขาย (SalesReports): รายการบิลพร้อมรายละเอียดสินค้า, เปรียบเทียบผลงานพนักงาน (ยอดขาย/จำนวนร้าน), ตัวกรองช่วงเวลา, ลบบิล (คืนสต็อกรถ)

3. **แผนที่ภาพรวม (Map Overview)**
   - Leaflet + ขอบเขต GeoJSON รายอำเภอของโคราช (ระบายสีแยกอำเภอ)
   - หมุดร้านตามสถานะ, วงกลมคลังสินค้า, วงกลมเป้าหมายสำรวจ (Geofence)
   - ตำแหน่งรถแบบเรียลไทม์ (poll ทุก 30 วินาที) + เส้นทาง GPS ย้อนหลังตามวันที่
   - ปุ่มขอเส้นทางนำทาง (Get Directions)

4. **การจัดการสินค้าและสต็อก (Inventory) — 4 แท็บ**
   - **สต็อกรถ (Vans):** ดูสต็อกคงเหลือแยกรายคัน
   - **คลังหลัก (Master):** ดู/แก้ไขจำนวนสินค้าในคลังหลัก
   - **แคตตาล็อก (Catalog):** เพิ่ม/แก้ไข/ลบสินค้า (name, sku, หมวดหมู่, ราคา)
   - **อ้างอิง POS (POS):** ดูสต็อกสดจากระบบ POS (line-commerce) แบบอ่านอย่างเดียว + ปุ่มนำเข้าแคตตาล็อกจาก POS
   - โอนสต็อกจากคลังหลักขึ้นรถ (`/api/inventory/transfer`) พร้อมบันทึก `stock_transactions`

5. **การจัดการทรัพยากร**
   - จัดการพนักงาน (EmployeeManagementPage): เพิ่ม/แก้ไข/ลบ, ทะเบียนรถ, พื้นที่รับผิดชอบ; แก้ชื่อพนักงานจะ cascade ไป `stores.created_by`
   - จัดการเป้าหมายสำรวจ (Survey Targets): เพิ่ม/ลบวงกลม geofence และมอบหมายให้พนักงาน

6. **การจัดการข้อมูลร้านค้าและตรวจสอบผลสำรวจ**
   - ร้านค้าและผลสำรวจ (StoreSurvey): ดู/แก้ไข/ลบร้าน (ลบแบบ cascade ไป sales, sale_items, visits)
   - ตรวจสอบผลสำรวจ (SurveyAudit): Approve / Reject ร้านที่สำรวจแล้ว (ตั้ง `verification_status`)

### 1.3 การเชื่อมต่อภายนอก (Integrations)

- **POS (line-commerce):** อ่านตาราง `pos.products` เพื่อ (ก) แสดงเป็นสต็อกอ้างอิงแบบอ่านอย่างเดียว และ (ข) นำเข้าเป็นแคตตาล็อก/คลังหลักของ Cashvan (`/api/products/sync-from-pos`) — ปลอดภัยเมื่อรันซ้ำ (จับคู่ด้วย `pos_product_id`; สต็อก MASTER ที่มีอยู่แล้วไม่ถูกแก้)
- **Cloudinary:** อัปโหลดรูปหน้าร้าน (unsigned preset)
- **LINE LIFF:** ยืนยันตัวตนพนักงาน
- **OpenStreetMap:** แผนที่ tile

## 2. สิ่งที่ไม่อยู่ในขอบเขต (Out-of-Scope)

1. **ระบบบัญชี/ภาษีแบบเต็มรูปแบบ** — ไม่ออกใบกำกับภาษีอัตโนมัติ (มีบันทึกการขายและรายงานกระทบยอดเท่านั้น)
2. **ระบบชำระเงินออนไลน์ (Payment Gateway)** — รับเงินสด/โอนนอกระบบ แล้วบันทึกยอดในระบบ
3. **แอปมือถือ Native (iOS/Android)** — ฝั่ง Driver เป็น Web App ผ่าน LINE LIFF เท่านั้น
4. **การจัดเส้นทางอัตโนมัติด้วย AI (Route Optimization)** — มีเพียงปุ่มขอเส้นทางนำทางปลายทางเดียว ยังไม่คำนวณลำดับร้านที่เหมาะสมที่สุด
5. **การเขียนข้อมูลกลับไปยังระบบ POS** — การเชื่อมต่อ POS เป็นแบบอ่านอย่างเดียว (one-way) เท่านั้น
6. **JWT / OAuth เต็มรูปแบบสำหรับ Admin** — ปัจจุบันใช้ token จำลอง (`fake-jwt-token-<id>`) และตรวจสิทธิ์ที่ฝั่ง client
