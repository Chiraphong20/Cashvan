# ข้อมูลอ้างอิงและตั้งค่าพื้นฐาน (Master Data / Lookup Data)

เอกสารฉบับนี้อธิบายชุดข้อมูลพื้นฐาน (Reference Data) ที่ระบบ Wae Jer Logistic ใช้อ้างอิงสำหรับการแสดงผลและบันทึกค่าในฐานข้อมูล

---

## 1. สถานะร้านค้า (Store Status / Visit Status)

สถานะของร้านค้าจะถูกใช้อ้างอิงใน 2 ตารางหลักคือ `stores.status` และ `visits.status`

| รหัสสถานะ (Code) | คำอธิบาย |
| :--- | :--- |
| `PENDING` | ร้านค้ายังไม่เคยได้รับการเยี่ยมชม หรือรอการตรวจสอบ |
| `SURVEYED` | พนักงานเข้าเยี่ยมและถ่ายภาพสำรวจเรียบร้อยแล้ว แต่อาจจะยังไม่ได้ขายสินค้า |
| `SUCCESS` | พนักงานเข้าเยี่ยมและมีการบันทึกการขายสินค้าสำเร็จ |
| `CLOSED` | พนักงานไปถึงร้านแล้วแต่ร้านปิด |
| `NOT_FOUND` | พนักงานลงพื้นที่แล้วไม่พบพิกัดร้านค้าตามที่ระบุ |
| `REJECTED` | (ใช้กับระบบ Admin) ปฏิเสธข้อมูลที่พนักงานส่งมา (Survey Audit) |
| `APPROVED` | (ใช้กับระบบ Admin) อนุมัติข้อมูลและภาพถ่ายของร้านค้า |

## 2. สถานะยานพาหนะ (Vehicle Status)

อ้างอิงจากตาราง `vehicles`

| รหัสสถานะ (Code) | คำอธิบาย |
| :--- | :--- |
| `ACTIVE` | รถพร้อมใช้งาน และพนักงานสามารถนำไปวิ่งงานได้ |
| `MAINTENANCE` | รถอยู่ระหว่างการซ่อมบำรุง ไม่สามารถเลือกขับได้ |
| `INACTIVE` | รถถูกยกเลิกการใช้งาน |

## 3. สถานะการทำงานของพนักงาน (Driver Work Status)

อ้างอิงจากตาราง `drivers`

| รหัสสถานะ (Code) | คำอธิบาย |
| :--- | :--- |
| `ON_DUTY` | พนักงานเช็คอินเริ่มงานแล้ว และกำลังขับรถอยู่ |
| `OFF_DUTY` | พนักงานปิดกะ หรือยังไม่เริ่มงาน |
| `ON_LEAVE` | พนักงานลา |

## 4. ประเภทคลังสินค้า (Inventory Location Type)

อ้างอิงจากตาราง `inventory` และใช้เป็น parameter ของ API

| ประเภท (Type) | ตัวอย่าง (Location ID) | คำอธิบาย |
| :--- | :--- | :--- |
| `MASTER` | `MASTER` | คลังสินค้าส่วนกลางของบริษัท (DC) |
| `VAN` | `V-01`, `V-02` | สต็อกสินค้าที่ถูกโอนย้ายไปอยู่บนรถแต่ละคัน (หน่วยรถ Cashvan) |

## 5. ประเภทของ Transaction สต็อก (Stock Transaction Type)

อ้างอิงจากตาราง `stock_transactions` ใช้สำหรับตรวจสอบ Audit Log ย้อนหลัง

| ประเภท (Transaction Type) | คำอธิบาย | พฤติกรรมที่เกิดขึ้น (Action) |
| :--- | :--- | :--- |
| `REFILL` | แอดมินเติมสินค้าจากคลังขึ้นรถ | `MASTER` (ลด), `VAN` (เพิ่ม) |
| `SALE` | พนักงานขายสินค้าได้ | `VAN` (ลด), `MASTER` (ไม่เปลี่ยน) |
| `RETURN` | ลูกค้าหรือพนักงานคืนสินค้ากลับคลัง | `VAN` (ลด), `MASTER` (เพิ่ม) |
| `ADJUSTMENT` | แอดมินปรับปรุงยอดนับสต็อก | ขึ้นอยู่กับการปรับเพิ่มหรือลด |

## 6. รหัสสินค้าหลักและหมวดหมู่ (Products & Categories)

ระบบมีข้อมูลหมวดหมู่ (Categories) ตั้งต้นในระบบดังนี้:
1. เครื่องดื่ม
2. ของขบเคี้ยว
*(หมายเหตุ: แอดมินสามารถเพิ่มหมวดหมู่หรือสินค้าได้จากระบบ Product Management ในภายหลัง)*

รหัสสินค้า (Product Code) จะมีรูปแบบมาตรฐานคือ `MOC-XXX` (เช่น MOC-001)
